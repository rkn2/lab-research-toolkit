# Research Paper Outline Template

Copy this file into your paper's repo or a new document and fill it in. It is organized in **LEAP writing order** — the order you should *write* in — not the order the paper is read in. See [Writing a Research Paper](../writing-a-paper.md) for the full method, and Peer Recognized's [How to Write a Research Paper](https://peerrecognized.com/how-to-write-a-research-paper/) for the source guide and its downloadable templates.

**How to use this template:**
- Work top to bottom. Do not skip ahead to the Introduction.
- Each section has a **key sentence** prompt. Write that one sentence first — it is the message of the section. If you cannot write the key sentence, you are not ready to write the section.
- Write badly first. Fill every bracket with *something*, then revise.
